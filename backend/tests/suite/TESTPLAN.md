# 标准测试集合：功能清单与三种身份的预期

共 44 个功能、226 个用例。每个用例分别用游客、注册用户、会员三种身份执行；“—”表示该身份不适用。
预期多为接口返回的 HTTP 状态：200 正常，401 未登录，402 需要会员或次数，403 无权限（游客不能做 / 没做过题 / 不是管理员），404 不存在或不是自己的，409 冲突（重复）。
